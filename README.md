prompt while I watched, and I filmed it. The video shows the prompt, the

network): catch falling stars in a basket. Arrow keys or mouse to move,
+1 per star, miss 3 and it's over, win at 20 stars.

**The video** (`video.mp4`, 1080×1920, ~36 s): hook → the prompt → real
code → real play-test → real gameplay → make.fun's referral end card
